## Hi there 👋

I give serious tools ridiculous names, then finish them anyway.

`Toybox` · `Icebox` · `Rubik's Cube` · `Fancy Calculator` · `Mario Pipe Lab`

Every one of those is a real repository. The naming is the only unserious part.

### 🧰 What's on the shelves

| | |
|---|---|
| **[Rubik-s-Cube](...)** | Nine Rust + egui desktop apps for ML/DL, numbered `00.` through `08.` — Faster R-CNN, beam search, Conv1D anomaly detection, k-means, active learning, a conv2d visualizer, a multi-agent physics sim, and a LightGBM-vs-ensemble bakeoff. Screenshots and builds you can double-click. |
| **[Orchestration](...)** | A visual DAG builder that exports real Airflow 2.x/3.x pipelines, and a CrewAI studio that generates deployable multi-agent crews. Walked through screen by screen. |
| **[Fancy-Calculator](...)** | A dated lab notebook of end-to-end studies: smartphone addiction, gene expression, Q-learning blackjack, predictive maintenance, a car repair assistant. There is no unifying theme. That *is* the theme. |
| **[Icebox](...)** | Elixir on the BEAM — a Phoenix LiveView community board that got badly out of hand, and a real-time chat in 1,500 lines. |
| **[Mario-pipe-lab](...)** | Jupyter sandbox for ETL and ML pipelines. Named after the pipes. Obviously. |
| **[Plain-Text](...)** | Three Rust text apps — LightNote, MarkdownEditor, Writing. Roughly 300 KB of Rust written to avoid using Notepad. |
