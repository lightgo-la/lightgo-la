## Hi there 👋

I give serious tools ridiculous names, then finish them anyway.

`Toybox` · `Icebox` · `Rubik's Cube` · `Fancy Calculator` · `Mario Pipe Lab`

Every one of those is a real repository. The naming is the only unserious part.

### 📓 Dated, not named

Open almost any repo of mine and you'll find folders like
`[21.04.26] Q-Learning rl_blackjack` and `[15.08.26] iris`.

I don't name experiments, I date them. One folder, one complete study, stamped
with the day it started. It's a lab notebook that occasionally compiles.

### 🧾 Proof, not promises

Most folders ship what actually came out the other end — screenshots, a written
report, a build you can run. If something claims to detect objects, there's a
picture of it detecting objects.

### 🔧 The rotation

**Python** to ask the question.
**Rust** when the answer needs a window and has to still be running tomorrow.
**Elixir** when several people have to be in the same room at once.
